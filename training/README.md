# training/

Material de treino. Só as demos do dicionário de efeitos vêm no repositório; o resto é local de cada pessoa (fora do git). `setup.sh` cria as pastas.

| Pasta | O que guarda |
|---|---|
| `dicionario-demo/`, `dicionario-demo-2/` | composições que validam os 44 efeitos de `references/motion-dictionary.md` (no git) |
| `voz/` | sua gravação para clonar a voz (1–2 min, só a sua voz). Dado biométrico: nunca suba. |
| `referencias/ref-NN.mp4` + `ref-NN/` | vídeos de referência e a análise gerada por `analyze_reference.sh` (vira estilo em `references/styles/`) |
| qualquer outra | testes de efeito, pesquisas, rascunhos |
