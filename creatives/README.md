# creatives/

Peças finais, criadas aqui pelo pipeline (fora do git). `setup.sh` cria as pastas.

| Pasta | O que guarda |
|---|---|
| `reels/` | vídeos: `<slug>-<preset>.mp4` (Reels, Stories, TikTok, Shorts, YouTube) |
| `carrossel/` | `<slug>-<preset>/NN.png` + `legenda.txt` + `alt-text.txt` |
| `post/` | post estático: `<slug>-<preset>.png` |
| `registro.md` | histórico das peças entregues, lido na etapa "Ideia central" (nasce de `.agents/skills/motion-cena/assets/registro.template.md`) |
